# Implementation contract

User approved MVP. Parent owns root config, shared DTOs, infrastructure, scripts, README and integration. API worker owns apps/api except providers. Provider worker owns apps/api/src/providers except media-provider.ts. UI worker owns apps/web. Shared workspace: preserve other work. No git operations by workers. Experiment B slot 09: no knowledge-vault notes.

API envelopes: GET kids/categories => Category[]; GET kids/categories/:id/media => { category: Category, media: ChildMedia[] }; GET kids/media/:id => ChildMedia. Child URLs always /api/kids/media/:id/play and /thumbnail. Child filtering on ALL endpoints.

GET admin/auth/session => { authenticated: boolean }; POST login { pin } => 204 + cookie; POST logout => 204. GET admin/media => LibraryResponse. PATCH admin/media/:id MediaUpdate => AdminMedia; DELETE => 204 (metadata only). Category GET => Category[], POST/PATCH CategoryInput => Category, DELETE => 204 (join cascade, keep media).

POST admin/import/youtube { url } => ImportJob (202). GET admin/import/:id => ImportJob. POST admin/import/:id/confirm ImportConfirmation => ImportJob. POST admin/import/:id/retry => ImportJob. GET admin/import/:id/thumbnail for protected preview. GET admin/local/candidates => LocalCandidate[]. POST admin/import/local { sourceId, categoryIds, visible } => AdminMedia (201). All categories assigned transactionally, unique(sourceType, sourceId). Stable error codes.

Config exports AppConfig and loadConfig(): databaseUrl, localMediaRoot (absolute), tubeArchivistUrl, tubeArchivistToken, host, port, publicOrigin, sessionHours, secureCookies, ffprobePath. Parent .env uses DATABASE_URL, LOCAL_MEDIA_ROOT, TUBE_ARCHIVIST_URL, TUBE_ARCHIVIST_TOKEN, HOST, PORT, PUBLIC_ORIGIN, SESSION_HOURS, SECURE_COOKIES, FFPROBE_PATH. Load root .env independent of cwd using dotenv, root path determined from import.meta.url (src and dist at same depth). Empty TA token allowed startup; local path works while TA setup pending. External error messages sanitized.

Providers exports agreed: LocalMediaProvider constructor(root: string, ffprobePath?: string), discover(): Promise<LocalCandidate[]> and MediaProvider methods. TubeArchivistService constructor(baseUrl: string, token: string); preview(videoId): Promise<{ taskId: string | null; metadata: MediaMetadata | null }>; pending(videoId): Promise<MediaMetadata | null>; archived(videoId): Promise<MediaMetadata | null>; queue(videoId): Promise<void>; failed(videoId): Promise<boolean>; resource(path: string, headers: {range?: string; ifRange?: string}, method?: 'GET'|'HEAD'): Promise<Response>; metadataResource(videoId): Promise<{mediaPath: string; thumbnailPath: string | null}>. YouTubeMediaProvider constructor(service), MediaProvider methods; exported youtubeIdFromUrl(url): string. ProviderError(code) exported in providers/errors.ts. HTTP uses allowlist origin/path, timeouts and never browser credentials. Naming no get prefix per workspace AGENTS.

Imports persist state then reconcile (timer in API, no extra worker process). Extraction success is NOT download success. YouTube preview may already be archived. Confirm must persist approval then trigger queue, idempotent retries; only create MediaItem when archived + available; pending approval never creates visible item. Store chosen categories/visibility in imports for completion. Never bulk start downloads. Reconcile on startup and interval with overlap protection; failed extraction eventually terminal, not endless EXTRACTING. Local register immediate. UI polls only in parent view and handles 401 centrally.

API package required commands dev (tsx watch), build (tsc), typecheck, test (node:test through tsx), db:migrate, pin. Production serves apps/web/dist via @fastify/static SPA fallback excluding /api. Range files served only after service approval with @fastify/static serve:false, constrained realpath. Parent worker owns tests and schemas/migrations.
